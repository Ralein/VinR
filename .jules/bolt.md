## 2024-05-26 - Parallelizing External HTTP Calls vs DB Calls
**Learning:** In this codebase, independent external API calls made with `httpx.AsyncClient` are not restricted by concurrency limitations. Unlike SQLAlchemy's `AsyncSession`—which is not concurrent-safe and prevents using `asyncio.gather` on single sessions—external HTTP calls can and should be parallelized to significantly reduce latency. I noticed this when the Eventbrite and Google Places searches were being run sequentially in `events_service.py`.
**Action:** Always check if multiple independent `httpx` API calls are being `await`ed sequentially. If they don't depend on each other, wrap them in `asyncio.gather` for immediate speed improvements without introducing thread-safety bugs. Keep database queries sequential on a single session or use separate session instances if true concurrency is required.
